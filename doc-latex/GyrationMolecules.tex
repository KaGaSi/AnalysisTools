\section{GyrationMolecules} \label{sec:GyrationMolecules}

\tt{GyrationMolecules} calculates the gyration tensor and shape descriptors for
individual molecules, producing one output file per molecule type.

The shape descriptors --- radius of gyration $R_\mathrm{G}$, asphericity $b$,
acylindricity $c$, and relative shape anisotropy $\kappa^2$ --- are defined in
\fullref{sec:GyrationAggregates} (\cref{eq:R_G,eq:b,eq:anis}). All beads are
treated with equal weight (geometric centre, not centre of mass).

For each selected molecule in each timestep, the gyration tensor is diagonalised
and the eigenvalues $\lambda_x^2 \leq \lambda_y^2 \leq \lambda_z^2$ are
obtained. These are averaged over all molecules of the same type in that
timestep and written to the output file, together with $\langle R_\mathrm{G}
\rangle$, $\langle R_\mathrm{G}^2 \rangle$, $\langle \kappa^2 \rangle$,
$\langle c \rangle$, $\langle b \rangle$, and the end-to-end distance $\langle
R_e \rangle$. After all timesteps are processed, overall averages are appended
to the same file.

The end-to-end distance $R_e$ is the straight-line distance between the first
and last bead in the molecule's bead list.

Use \tt{-bt} to restrict the gyration calculation to specific bead types;
molecules with fewer than two beads of the selected types are skipped.
Note that $R_e$ always uses the first and last bead of the full molecule
regardless of \tt{-bt}.

By default, \tt{GyrationMolecules} removes periodic boundary conditions from
each molecule before computing the tensor (\tt{--joined} skips this step when
the input already contains joined coordinates). Use \tt{-mt} to restrict the
calculation to specific molecule types (default: all).

\vspace{1em}
\noindent
Usage: \tt{GyrationMolecules <input> <output> [options]}

\noindent
\begin{longtable}{p{0.22\textwidth}p{0.724\textwidth}}
  \toprule
  \multicolumn{2}{l}{Mandatory arguments}\\
  \midrule
  \tt{<input>}  & input coordinate file\\
  \tt{<output>} & output base name; \tt{-<molname>.txt} is appended per
                  molecule type\\
  \toprule
  \multicolumn{2}{l}{Options}\\
  \midrule
  \tt{-mt <name(s)>} & molecule types to calculate for (default: all)\\
  \tt{-bt <name(s)>} & bead types to include in the gyration calculation
                       (default: all); does not affect $R_e$\\
  \tt{--joined}      & input already contains joined (unwrapped) coordinates;
                       skip PBC removal\\
  \midrule
  \multicolumn{2}{p{0.948\textwidth}}{\tt{-i}, \tt{-ft}, \tt{-st}, \tt{-e},
    \tt{-sk}, \tt{--verbose}, \tt{--silent}, \tt{--help}, \tt{--version}}\\
  \bottomrule
\end{longtable}

\noindent
Format of output files (one per molecule type, \tt{<output>-<molname>.txt}):
\begin{itemize}[nosep,leftmargin=5pt]
  \item 1st line: command used to generate the file
  \item 2nd line: molecule type name
  \item 3rd line: column headers
    \begin{itemize}[nosep,leftmargin=10pt]
      \item (1) timestep
      \item (2) $\langle R_\mathrm{G} \rangle$
      \item (3) $\langle R_\mathrm{G}^2 \rangle$
      \item (4) $\langle \kappa^2 \rangle$ (relative shape anisotropy)
      \item (5) $\langle c \rangle$ (acylindricity)
      \item (6) $\langle b \rangle$ (asphericity)
      \item (7--9) $\langle \lambda_x^2 \rangle$, $\langle \lambda_y^2 \rangle$,
        $\langle \lambda_z^2 \rangle$ (eigenvalues, ascending)
      \item (10) $\langle R_e \rangle$ (end-to-end distance)
    \end{itemize}
  \item subsequent lines: per-timestep averages over all molecules of this type
  \item last three lines (commented out): overall-average header and values for
    all columns except timestep
\end{itemize}
