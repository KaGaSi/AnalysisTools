\section{BondLength} \label{sec:BondLength}

\tt{BondLength} calculates distributions of bond lengths for specified molecule
type(s), grouped by bead type pair. It can also calculate distributions of
distances between arbitrary bead pairs within those molecules.

For each selected molecule type, bond lengths are accumulated into distributions
per bead type pair. For example, a molecule A-B-B has two distinct bond types,
A-B and B-B, so the output contains one distribution column for each. By default,
all molecule types are used; restrict this with \tt{-mt}. Adding \tt{--all}
generates additional per-individual-bond distributions alongside the per-type-pair
ones --- bond 1, bond 2, ..., in the order they appear in the structure file.
This is useful when bonds of the same bead type pair are structurally
inequivalent.

If the coordinate file contains molecules split across periodic boundaries,
\tt{BondLength} joins them before the calculation. Supply \tt{--joined} if the
coordinates are already whole-molecule to skip this step.

The \tt{-n} option computes distributions of distances between arbitrary bead
pairs, not just bonded ones. Pairs are given as consecutive 1-based bead indices
(in the order beads appear in the structure file) after the output filename:
\tt{-n dist.txt 1 5} measures the distance between beads 1 and~5, and multiple
pairs can be specified at once, e.g.\ \tt{-n dist.txt 1 5 2 4}. If an index
exceeds the number of beads in the molecule, the last bead is used; if no indices
are given, the first and last bead of each molecule are used as the default pair.
The \tt{-w} option emits a warning whenever a bond length exceeds the given
threshold.

The \tt{-t} option writes per-timestep averages to a separate file. The columns
follow the same order as in the main output file: bead type pair averages (and,
if \tt{--all} is used, individual bond averages; and, if \tt{-n} is used, bead
pair distance averages).

\noindent
\tt{Usage: BondLength <input> <width> <output> [options]}

\noindent
\begin{longtable}{p{0.24\textwidth}p{0.706\textwidth}}
  \toprule
  \multicolumn{2}{l}{Mandatory arguments} \\
  \midrule
  \tt{<input>}  & input coordinate file \\
  \tt{<width>}  & bin width for the distribution \\
  \tt{<output>} & output file with bond length distributions \\
  \toprule
  \multicolumn{2}{l}{Options} \\
  \midrule
  \tt{-mt <name(s)>}    & molecule type(s) to use (default: all) \\
  \tt{--joined}         & input already contains joined (whole-molecule)
                          coordinates \\
  \tt{--all}            & also write per-individual-bond distributions \\
  \tt{-n <file> [ints]} & write distance distributions for specified bead
                          index pairs to \tt{<file>}; \tt{[ints]} are pairs
                          of 1-based bead indices (default: first and last
                          bead of each molecule) \\
  \tt{-w <float>}       & warn when a bond length exceeds \tt{<float>} \\
  \tt{-t <file>}        & write per-timestep average bond lengths to
                          \tt{<file>} \\
  \midrule
  \multicolumn{2}{p{0.948\textwidth}}{\tt{-i}, \tt{-ft}, \tt{-st}, \tt{-e},
    \tt{-sk}, \tt{--verbose}, \tt{--silent}, \tt{--help}, \tt{--version}} \\
  \bottomrule
\end{longtable}

\noindent
Format of output files:
\begin{enumerate}[nosep,leftmargin=20pt]
  \item \tt{<output>} --- bond length distributions grouped by bead type pair
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item next lines (one per selected molecule type): comment lines listing
        column numbers and their bead type pair labels; if \tt{--all} is used,
        the range of individual bond columns is noted at the end of each line
      \item data lines: column 1 is the bin centre; remaining columns are
        normalised bond length distributions
      \item second-to-last line: comment line mapping column numbers to bead
        type pairs, three columns per pair in the order min, max, average
      \item last line: commented-out minimum, maximum, and average lengths for
        each pair
    \end{itemize}
  \item \tt{-n <file>} --- distance distributions for specified bead pairs
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item 2nd line: bead names in order for each selected molecule type
      \item next lines: comment lines listing column numbers and bead index
        pairs (written as smaller-index -- larger-index)
      \item data lines: column 1 is the bin centre; remaining columns are
        normalised distance distributions
      \item second-to-last line: comment line mapping column numbers to bead
        index pairs, three columns per pair in the order min, max, average
      \item last line: commented-out minimum, maximum, and average distances
    \end{itemize}
  \item \tt{-t <file>} --- per-timestep average bond lengths
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item next lines: comment lines describing each column (bead type pairs;
        if \tt{--all}, the range of individual bond columns; if \tt{-n}, the
        bead pair distance columns)
      \item data lines: column 1 is the timestep number; remaining columns are
        per-timestep mean values in the same order as in \tt{<output>}
    \end{itemize}
\end{enumerate}
