\section{DensityBox} \label{sec:DensityBox}

\tt{DensityBox} calculates number density profiles along all three box axes for
every bead type, producing one output file per axis.

The box is divided into slices of thickness \tt{<width>} perpendicular to each
axis in turn. The number density of bead type $i$ in a slice at position
$\alpha$ is
\begin{equation}
  \rho_i(\alpha) = \frac{\langle N_i(\alpha) \rangle}
                   {\Delta\alpha\, L_\beta\, L_\gamma},
\end{equation}
where $\langle N_i(\alpha) \rangle$ is the time-averaged number of type-$i$ beads
in the slice, $\Delta\alpha$ is the slice thickness (i.e., \tt{<width>}), and
$L_\beta$, $L_\gamma$ are the box lengths along the remaining two axes.

Three output files are created automatically, named \tt{<output>-x.txt},
\tt{<output>-y.txt}, and \tt{<output>-z.txt}. Bead types that never appear
in the trajectory are silently omitted from the output columns.

By default, all beads --- bonded and unbonded --- contribute to the density.
Because the utility groups them by bead type name, beads with the same name
in different molecule types are indistinguishable. To obtain separate density
profiles for overlapping bead types, use \tt{-x} to exclude specific molecule
types, running the utility twice with complementary exclusion sets (note that
unbonded beads cannot be excluded and will always appear in both outputs).

The \tt{--per-bead} option switches the grouping from bead type to bead position
within each molecule type. Each column then represents the $k$-th bead of a
given molecule type (column label \tt{MolName:k}, 1-indexed), which reveals
how density varies along the chain. Unbonded beads are skipped in this mode.

\tt{DensityBox} requires an orthogonal box with constant side lengths; a
triclinic box or a varying box size will produce unreliable results.

\noindent
\tt{Usage: DensityBox <input> <width> <output> [options]}

\noindent
\begin{longtable}{p{0.22\textwidth}p{0.726\textwidth}}
  \toprule
  \multicolumn{2}{l}{Mandatory arguments} \\
  \midrule
  \tt{<input>}  & input coordinate file \\
  \tt{<width>}  & slice thickness \\
  \tt{<output>} & base name for the three output files; suffixed automatically
                  with \tt{-x.txt}, \tt{-y.txt}, and \tt{-z.txt} \\
  \toprule
  \multicolumn{2}{l}{Options} \\
  \midrule
  \tt{-x <name(s)>} & exclude beads belonging to the specified molecule
                      type(s) \\
  \tt{--per-bead}   & output density per bead position within each molecule
                      type, rather than per bead type \\
  \midrule
  \multicolumn{2}{p{0.948\textwidth}}{\tt{-i}, \tt{-ft}, \tt{-st}, \tt{-e},
    \tt{-sk}, \tt{--verbose}, \tt{--silent}, \tt{--help}, \tt{--version}} \\
  \bottomrule
\end{longtable}

\noindent
Format of output files (\tt{-x.txt}, \tt{-y.txt}, \tt{-z.txt} are identical in
structure):
\begin{enumerate}[nosep,leftmargin=20pt]
  \item one density file per axis, e.g.\ \tt{<output>-z.txt}
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item 2nd line: column headers
        \begin{itemize}[nosep,leftmargin=10pt]
          \item column 1: bin centre (distance from the box origin along the
            given axis); e.g., with \tt{<width>} = 0.5, the first centre is
            0.25, the second is 0.75, etc.
          \item remaining columns: number density per bead type (default) or
            per bead position within each molecule type (\tt{--per-bead}),
            labelled by bead type name or \tt{MolName:k} respectively
        \end{itemize}
      \item data lines: bin centres and corresponding densities
    \end{itemize}
\end{enumerate}
