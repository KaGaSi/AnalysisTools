\section{Surface} \label{sec:Surface}

\tt{Surface} identifies the two surfaces of a layered structure (e.g.\ a polymer
brush or a lipid bilayer) and writes their time-averaged coordinates and areas.

The algorithm is based on the Identification of the Truly Interfacial Molecules
(ITIM) method \todo{add citation: Pártay et al., J. Comput. Chem. 29:945 (2008)}.
A grid of probe spheres of radius $r$ (set via \tt{-r}, default 0.5) is placed
in the plane perpendicular to \tt{<axis>}, with a spacing of \tt{<width>}
between adjacent probes. For each probe, the bead whose sphere (of radius $R_k$,
defaulting to 0.5 if not specified in the structure file) overlaps the probe
sphere and whose coordinate along \tt{<axis>} is most extreme defines the surface
at that grid point. Two surfaces are found per probe position (labelled
\enquote{surface 1} and \enquote{surface 2}), corresponding to the two sides of
the structure.

The utility operates in two modes:
\begin{itemize}
  \item \textbf{Default (from the box centre):} probes approach from the box
    centre outward towards both walls. This finds the innermost extent of each
    layer, i.e.\ the surface facing the solvent gap between the layers. Use this
    for structures such as a polymer brush grafted on both walls.
  \item \textbf{\tt{--in} (from the box edges):} probes approach from both walls
    inward towards the centre. This finds the outermost extent of a structure
    sitting inside the box, i.e.\ the outer leaflets. Use this for structures
    such as a lipid bilayer.
\end{itemize}

\vspace{1em}
By default all beads contribute to the surface search. Use \tt{--bonded} to
restrict this to beads in molecules, or \tt{-bt} to restrict to specific bead
types. If both \tt{--bonded} and \tt{-bt} are given, \tt{--bonded} takes
precedence. Beads without a radius defined in the structure file receive radius
0.5 automatically, and a warning is printed.

The surface area is computed by triangulating the grid: each pair of adjacent
grid cells is split into two triangles using Heron's formula, and the triangle
areas are summed and scaled to the actual box area. Three areas are reported per
timestep: surface~1, surface~2, and a \enquote{middle surface} at their midpoint.
Use \tt{-a} to write these per-timestep areas; the overall averages are appended
at the end of that file.

The \tt{-wd} option writes the distribution of surface thickness (i.e.\ the
distance $|\text{surface\,1} - \text{surface\,2}|$ at each grid point and
timestep) to a file. The \tt{-w} option writes the per-timestep average
thickness. \todo{Verify whether -w can be used independently of -wd; source
TODO flags a possible inconsistency between the two.}

The \tt{-b} option saves the detected surface beads to a coordinate file at each
timestep. Beads that are present in the trajectory but not identified as surface
beads are written with coordinates $(0, 0, 0)$ so that they remain invisible in
typical visualisation tools without disturbing the frame count.

\tt{Usage: Surface <input> <width> <surf.txt> <axis> [options]}

  \toprule
  \multicolumn{2}{l}{Mandatory arguments} \\
  \midrule
  \tt{<input>}    & input coordinate file \\
  \tt{<width>}    & probe grid spacing (side length of each grid square) \\

  \multicolumn{2}{l}{Options} \\

  \tt{--bonded}        & use only beads belonging to molecules \\
  \tt{-bt <name(s)>}   & use only the specified bead type(s) \\
  \tt{-r <float>}      & probe radius (default: 0.5) \\
  \tt{-a <area.txt>}   & write per-timestep surface areas to \tt{<area.txt>} \\
  \tt{-wd <file> <w>}  & write distribution of surface thickness to

  \bottomrule

\noindent
Format of output files:
\begin{enumerate}[nosep,leftmargin=20pt]
  \item \tt{<surf.txt>} --- time-averaged surface coordinates on the 2D grid
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item 2nd line: column headers:
        the two in-plane coordinates (columns 1--2), surface~1, surface~2,
        and average surface coordinates along \tt{<axis>} (columns 3--5)
      \item data block: one line per grid point; the grid varies the second
        in-plane coordinate (inner loop) and the first (outer loop), with a
        blank line separating each row of the outer coordinate
    \end{itemize}
  \item \tt{-a <area.txt>} --- per-timestep surface areas
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item 2nd line: column headers: (1)~timestep, (2)~area of surface~1,
        (3)~area of surface~2, (4)~area of the middle surface
      \item data lines: one per timestep
      \item last two lines: overall average areas (header then values) for
        surface~1, surface~2, and the middle surface
    \end{itemize}
  \item \tt{-wd <file>} --- distribution of surface thickness
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item 2nd line: column headers: (1)~bin centre, (2)~normalised count
      \item data lines: thickness distribution
      \item last line: commented-out overall average thickness
    \end{itemize}
  \item \tt{-w <file>} --- per-timestep average surface thickness
    \begin{itemize}[nosep,leftmargin=5pt]
      \item 1st line: command used to generate the file
      \item 2nd line: column headers: (1)~timestep, (2)~thickness
      \item data lines: one per timestep
      \item if \tt{-wd} is also used: overall average thickness appended at the
        end as a comment
    \end{itemize}
  \item \tt{-b <file>} --- coordinate file with surface beads per timestep;
    non-surface beads present in the timestep are written with coordinates
    $(0, 0, 0)$
\end{enumerate}
