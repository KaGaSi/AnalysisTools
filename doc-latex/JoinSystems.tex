\section{JoinSystems} \label{sec:JoinSystems}

\input{JoinSystems-tikz}

\tt{JoinSystems} merges two coordinate files into a single new system containing
all beads from both.

With no options the two systems are placed as-is: the output simulation box is
the smallest orthogonal box that simultaneously encompasses both input boxes,
and all bead coordinates are left unchanged (\cref{fig:JoinSystems-b}). The
input files can have different lower-bound offsets; \tt{JoinSystems} reads those
bounds and aligns the two systems correctly before computing the output box.

\paragraph{Offsetting the second system (\tt{-off}).}
The second system can be shifted relative to the first using
\tt{-off <x> <y> <z>}, where each component is either a number or \tt{c}.
A numeric value displaces all beads in the second system by that amount in the
given direction. Without \tt{--real}, the value is a fraction of the
\emph{first} system's box length in that direction; with \tt{--real} it is in
absolute coordinate units. Specifying \tt{c} for a direction aligns the centre
of the second system's box with the centre of the first system's box in that
direction (\cref{fig:JoinSystems-d}), regardless of \tt{--real}. The output
box is the smallest encompassing box computed \emph{after} the offset is applied.

\paragraph{Overriding the output box (\tt{-b}).}
\tt{-b <x> <y> <z>} replaces the automatically computed encompassing box with
an explicitly specified one. The new box is centred on the centre of the
encompassing box (\cref{fig:JoinSystems-c}), so bead coordinates do not move.
No check is performed to verify that all beads fall within the new box.
\tt{-off} and \tt{-b} can be combined: the offset is applied first, the
encompassing box is computed, and then \tt{-b} overrides it
(\cref{fig:JoinSystems-e}).

\paragraph{Output files.}
The output can be any supported coordinate format. An additional structure file
can be produced with \tt{-o}. Note that some formats (\ltrj) store explicit
box bounds, while others (\vtf) store only sidelengths; when the output is
\vtf, all coordinates are shifted so the box origin is at zero, which changes
the absolute positions of beads relative to the input.

\paragraph{Per-file input options.}
Because two input files are used, the usual structure-file (\tt{-i}) and
starting-timestep (\tt{-st}) options are suffixed with \tt{1} or \tt{2} to
indicate which file they apply to. For LAMMPS \data input, the starting-step
option has no effect since those files contain only a single timestep.

These examples are available in the \tt{Examples/JoinSystems} directory.

\noindent
Usage: \tt{JoinSystems <input1> <input2> <output> [options]}

  \multicolumn{2}{l}{Options}\\

  \tt{-off <x>|c <y>|c <z>|c}  & shift the second system; each component is

                                  (or absolute with \tt{--real}), or \tt{c}
                                  to align box centres\\

                                  sidelengths; box centred on the smallest
                                  encompassing box\\
