\section{Aggregates} \label{sec:Aggregates}

\tt{Aggregates} determines which molecules belong to which aggregate and writes
the result to an \tt{.agg} file (see Section~\ref{sec:AggFile}). The \tt{.agg}
file is the required input for aggregate-analysis utilities such as
\fullref{sec:AggNumber}, \fullref{sec:GyrationAggregates}, and
\fullref{sec:DensityAggregates}.

\subsection{Contact detection} \label{subsec:Aggregates-contact}

Two beads from different molecules form a \emph{contact pair} if their distance
is at most \tt{-d} (default: 1). Two molecules are \emph{connected} if they
share at least \tt{-c} contact pairs (default: 1). Distances are calculated
with periodic boundary conditions; use \tt{--no_pbc} to ignore them.

By default all bead types and all possible bead type pairs are used. The
\tt{-bt <bead(s)>} option restricts detection to the listed types, checking all
pairwise combinations among them (including same-type). For example, \tt{-bt A B}
checks A-A, A-B, and B-B contacts.

Adding \tt{--pairs} changes the interpretation of \tt{-bt}: the arguments are
read as consecutive bead type pairs rather than a type list, so \tt{-bt A B
--pairs} checks only A-B contacts, and \tt{-bt A B C D --pairs} checks A-B and
C-D. The \tt{--pairs} option requires the \tt{-bt} one.

\subsection{Aggregate identification} \label{subsec:Aggregates-dbscan}

Aggregates are found using DBSCAN at the molecule level: a molecule is a
\emph{core point} if it has at least \tt{-nbr} connected neighbours (default:
1); a molecule with fewer neighbours that is nonetheless reachable from a core
point is a \emph{border point}; all remaining molecules become singletons. The
core/border split is recorded in the \tt{.agg} file; singletons appear as a
single core molecule with no border molecules.

The default \tt{-nbr 1} makes every connected molecule a core point, so the
algorithm reduces to simple connected components and no border molecules arise.
Raising \tt{-nbr} is useful when loose contacts should not extend clusters into
spiderweb-like structures.

\subsection{Additional output} \label{subsec:Aggregates-output}

\subsubsection*{Joined coordinates}

The \tt{-j <file>} option writes a coordinate file with PBC removed for
aggregates: each aggregate's molecules are shifted so they appear connected
across box boundaries, with the aggregate's centre of mass inside the simulation
box. This is useful for visualization and avoids repeated PBC-removal for
aggregates in subsequent analyses.

\subsubsection*{Wall separation}

The \tt{-w <a> <float(s)>} option separates wall-touching aggregates from bulk
ones. \tt{<a>} is the axis perpendicular to the wall(s) (\tt{x}, \tt{y}, or
\tt{z}); the floating-point argument(s) give the wall coordinate(s) along that
axis. An aggregate is wall-touching if any of its \tt{-bt} beads lies within the
contact distance \tt{-d} of a wall. For example, in a box of side 10 with slit
walls in the xy-plane, \tt{-w z 1 9} could be used.

Two extra \tt{.agg} files are written alongside the main output:
\tt{<out>_w.agg} for wall-touching aggregates and \tt{<out>_b.agg} for bulk
aggregates (the main file still contains all aggregates). When \tt{-j} is also
used, matching joined-coordinate files with \tt{_w}/\tt{_b} suffixes are
created as well.

\subsubsection*{Coupling between output files}

The main \tt{<out.agg>} is linked to the coordinate file used to generate it:
most downstream utilities read both files together, so they must cover the same
timesteps. When \tt{-st}, \tt{-e}, or \tt{-sk} are used, the resulting
\tt{.agg} file is no longer tied to the original coordinate file but is coupled
with the \tt{-j} output (if given); only use the two coupled files for further
analysis.

\noindent
Output files:
\begin{enumerate}[nosep,leftmargin=20pt]
  \item \tt{<out.agg>} -- aggregate data for all aggregates in each timestep;
    format described in Section~\ref{sec:AggFile}
  \item \tt{-j <file>} -- coordinate file (format from extension) with PBC
    removed per aggregate; one timestep per input frame, matching
    \tt{<out.agg>}
  \item \tt{-w <a> <float(s)>} -- two additional \tt{.agg} files:
    \tt{<out>\_w.agg} for wall-touching aggregates and \tt{<out>\_b.agg} for
    bulk aggregates; if \tt{-j} is used, two matching joined-coordinate files
    are also written
\end{enumerate}
