\section{AggNumber} \label{sec:AggNumber}

\tt{AggNumber} calculates the time evolution of average aggregate sizes,
distributions of aggregate sizes, and/or composition distributions of aggregates
of specified sizes from an \tt{agg} file (see Section~\ref{sec:AggFile}). At
least one of the \tt{-a}, \tt{-d}, and \tt{-c} options must be specified.

For a quantity $\mathcal{O}$ measured per aggregate, its number, weight, and z
averages are
\begin{equation}\label{eq:Avg}
  \langle\mathcal{O}\rangle_{\text{n}} = \frac{\sum_i N_i\mathcal{O}_i}{N},
  \qquad
  \langle\mathcal{O}\rangle_{\text{w}} =
    \frac{\sum_i N_i m_i\mathcal{O}_i}{\sum_i N_i m_i},
  \qquad
  \langle\mathcal{O}\rangle_{\text{z}} =
    \frac{\sum_i N_i m_i^2\mathcal{O}_i}{\sum_i N_i m_i^2},
\end{equation}
where $N$ is the total number of measured aggregates, $N_i$ is their number with
value $\mathcal{O}_i$, and $m_i$ is the mass of aggregate $i$.

The number, weight, and z distribution functions of aggregate sizes are
\begin{equation} \label{eq:Fnwz}
  F_{\text{n}}(A_\text{S}) = \frac{N_{A_{\text{S}}}}{N},
  \qquad
  F_{\text{w}}(A_\text{S}) = \frac{N_{A_{\text{S}}} m_{A_{\text{S}}}}{M},
  \qquad
  F_{\text{z}}(A_\text{S}) =
    \frac{N_{A_{\text{S}}} m^2_{A_{\text{S}}}}{\sum_{A_{\text{S}}} N_i m_i^2},
\end{equation}
where $N_{A_\text{S}}$ and $m_{A_\text{S}}$ are the count and mass of aggregates
with size $A_\text{S}$, $M$ is the total mass of all measured aggregates, and
the distributions are normalised to $\sum F_x(A_\text{S}) = 1$.

\subsection{Aggregate size} \label{subsec:AggNumber-size}

By default, the aggregate size $A_\text{S}$ is the total number of molecules in
the aggregate. The \tt{-m}, \tt{-x}, and \tt{-only} options alter both which
aggregates are considered and how their size is defined:

\begin{itemize}
  \item \tt{-m <name(s)>}: $A_\text{S}$ counts only the specified molecule
    types; aggregates where this count is zero are skipped.
  \item \tt{-x <name(s)>}: aggregates composed exclusively of the specified
    molecule type(s) are excluded.
  \item \tt{-only <name(s)>}: only aggregates whose molecules all belong to the
    specified type(s) are included.
\end{itemize}

These can be combined freely. For example, \tt{-only A B -x A} selects
aggregates composed only of \tt{A} and \tt{B} molecules but further excludes
those containing only \tt{A}. The \tt{-n <int> <int>} option restricts the
analysis to a given range of $A_\text{S}$ as defined by the options above.

\subsection{Mass definition} \label{subsec:AggNumber-mass}

When the \tt{-m} option is used, aggregate mass can be defined as either the
\enquote{partial mass} (mass of the \tt{-m}-selected molecule types only) or
the \enquote{total mass} (mass of all molecules in the aggregate). Both give
physically meaningful weight and z averages of aggregate size and size
distributions, so the \tt{-a} and \tt{-d} output files provide both. For all
other quantities (average aggregate mass $\langle M\rangle$, shape descriptors
from \tt{GyrationAggregates}, etc.) only total mass is physically meaningful, so
only total-mass-based values are written. When \tt{-m} is not used, partial and
total mass are identical and only one set of values is needed; the output files
provide two identical columns for easier parsing.

\noindent
Format of output files:
\begin{enumerate}[nosep,leftmargin=20pt]
  \item \tt{-a <file>} -- per-timestep averages
    \begin{itemize}[nosep,leftmargin=5pt]
      \item first two lines: AnalysisTools version and the command used
      \item third line: column headers
        \begin{itemize}[nosep,leftmargin=10pt]
          \item \tt{step}: simulation timestep
          \item \tt{<As>_n}: number-average aggregate size
          \item \tt{<As>_w}, \tt{<As>_z}: weight and z averages of $A_\text{S}$
            (Eq.~\eqref{eq:Avg}); two columns each, one using partial mass and
            one using total mass (Section~\ref{subsec:AggNumber-mass})
          \item \tt{<M>_n}, \tt{<M>_w}, \tt{<M>_z}: number, weight, and z
            averages of aggregate mass (total mass only;
            Eq.~\eqref{eq:Avg})
          \item \tt{<name>_n} for each molecule type: average count of that
            type per aggregate; summing over all types gives \tt{<As>_n}
          \item \tt{n_agg}: number of eligible aggregates in the timestep
        \end{itemize}
      \item fourth line: note explaining the partial/total mass distinction
      \item data lines follow; all values are zero in timesteps where no
        eligible aggregates exist
      \item last two lines: overall averages across the entire run, commented
        with \tt{\#}; same quantities as the per-timestep columns except
        \tt{n_agg} is replaced by \tt{<n_agg>} (mean number of aggregates
        per timestep)
    \end{itemize}
  \item \tt{-d <file>} -- distribution of aggregate sizes
    \begin{itemize}[nosep,leftmargin=5pt]
      \item first two lines: AnalysisTools version and the command used
      \item third line: column headers
        \begin{itemize}[nosep,leftmargin=10pt]
          \item \tt{As}: aggregate size
          \item \tt{F_n(As)}, \tt{F_w(As)}, \tt{F_z(As)}: number, weight,
            and z distribution functions (Eq.~\eqref{eq:Fnwz}); two columns
            for \tt{F_w(As)} and \tt{F_z(As)}, one per mass definition
          \item \tt{n_agg}: total count of aggregates of this size across all
            timesteps
          \item \tt{<name>_n} for each molecule type: average count of that
            type in an aggregate of this size
        \end{itemize}
      \item fourth line: note explaining the partial/total mass distinction
      \item data lines follow; only sizes observed at least once are written
      \item last two lines: same overall averages as in \tt{-a}
    \end{itemize}
  \item \tt{<file>-<NNN>.txt} from \tt{-c} -- per-type composition distribution
    \begin{itemize}[nosep,leftmargin=5pt]
      \item first two lines: AnalysisTools version and the command used
      \item third line: total number of aggregates of the given size found
        across all timesteps
      \item fourth line: column headers -- (1) number of molecules of a given
        type (from 0 to $A_\text{S}$); one column per molecule type giving
        the fraction of aggregates containing exactly that many of that type
      \item data lines follow; all molecule types present in the aggregate
        are counted, regardless of the \tt{-m} option
    \end{itemize}
  \item \tt{<file>_r-<NNN>.txt} from \tt{-c} -- pairwise composition distribution
    \begin{itemize}[nosep,leftmargin=5pt]
      \item first two lines: AnalysisTools version and the command used
      \item third line: total number of aggregates of the given size
      \item fourth line: column headers -- (1--2) counts of two molecule
        types; one column per distinct molecule-type pair giving the fraction
        of aggregates with exactly those counts; pairs with no observations
        are printed as \tt{?}
      \item data lines follow (only rows where at least one pair has a
        non-zero value); a blank line separates blocks where the first-column
        count changes, making the file directly usable as a gnuplot 3D dataset
    \end{itemize}
\end{enumerate}
