# Examples for AnalysisTools

This directory contains examples showing the possibilities of the individual
AnalysisTools utilities. Generally speaking, the examples are not meant as
tutorials. They assume you have already looked through the manual and are
comfortable with the basic command-line interface, including bash scripting.

The Scripts folder, on the other hand, contains workflow examples for data
analysis combining different AnalysisTools utilities as well as using other
codes, like VMD for visualization of simulation boxes, or gnuplot for generating
high-quality graphs
